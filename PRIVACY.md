# VerseLens Privacy Policy

VerseLens does not collect, store or transmit personal information. It has no user accounts, no analytics and no advertising, and it sends nothing about you or your screen to the developer or anyone else.

## Screen content
When you search with the hotkey or the automatic search, VerseLens captures a small area of the screen around the cursor and recognizes its text on your computer. The captured images and the recognized text are processed in memory only. They are not saved and not sent anywhere.

## Opening references
A found bible reference is opened in your default web browser on [bibleserver.com](https://www.bibleserver.com), or on [bible.com](https://www.bible.com) if you choose it in the settings. The address contains only the reference and the chosen translations. What these pages do with that visit is covered by their own privacy policies. A lookup script you add and choose in the settings opens the web page it names instead.

## Local data
Settings and log files are stored only on your computer, in the VerseLens folder of the local app data folder. The logs help diagnose problems. They record the references that were found, file paths on your computer, which can contain your Windows user name, and occasionally a single word recognized on the screen when the recognition goes wrong. The logs keep the last 20 sessions and never leave your computer unless you share them yourself.

Uninstalling VerseLens removes the settings and log files it created.

## Updates
The Microsoft Store version is updated by the Microsoft Store. The version installed from GitHub checks the [GitHub releases](https://github.com/michael-b3n/biblia/releases) of the project for new versions and downloads them from there. This check sends no personal information, GitHub receives the usual information of a web request such as your IP address.
